# PachaByte — Documentación maestra v1.0

Paquete de transferencia para agentes de programación, diseño, narrativa y arte. Especificación de **un juego previsto**, no prueba de implementación. Idioma: español.

## Orden de lectura obligatorio
1. `AGENTS.md` — cómo actuar y pedir recursos.
2. `DECISIONS.md` — qué es canon, propuesta o pendiente.
3. `GAME_VISION.md` y `WORLD_LORE.md` — identidad e historia.
4. `WORLD_MAP.md`, `CHARACTERS.md`, `LEVEL_DESIGN.md` — mundo, personajes, recorrido.
5. `GDD.md`, `COMBAT_DESIGN.md` — sistemas jugables.
6. `ART_BIBLE.md`, `ASSET_PIPELINE.md`, `ASSET_REQUEST_TEMPLATE.md` — arte y coordinación con el usuario.
7. `NARRATIVE_SCRIPT.md`, `IMPLEMENTATION_PLAN.md` — guion, etapas y verificación.

**Frase guía:** En un Perú fantástico conectado por la Trama de Pacha, Kipu combate bugs, repara rutas, libera guardianes tecnológicos corrompidos y aprende a reescribir proyectiles mediante PachaShift.

**Referencia visual principal:** lámina de diseño Kipu/Amaru-01 compartida y reafirmada en el chat, con turquesa/oro, Amaru serpentino, panel de animaciones, comparación 320×180 y modo Nokia. Adjuntar el archivo original a `assets/references/` cuando esté disponible. NO asumir que este paquete incluye imágenes; NO reemplazar la lámina por otra imagen aleatoria.

El arte de concepto NO es un PNG RGBA dimensionado ni una spritesheet verificada. Los scripts, builds, assets y rutas existentes se deben inspeccionar en el repositorio real antes de continuar.
